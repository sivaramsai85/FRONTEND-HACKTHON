EDUREPORT - HOD + MULTI-FACULTY UPDATE

WHAT WAS ADDED
1. A separate HOD Login option on the portal selection page.
2. HOD can create faculty accounts with name, email, password, department and designation.
3. HOD can view the faculty account list and remove faculty accounts.
4. Every created faculty account can log in through Faculty Login and access the existing student dashboard, student records, reports and analytics.
5. The existing starter faculty account is retained.

HOW TO RUN (OPEN THIS PROJECT FOLDER IN VS CODE)
1. Open the folder that directly contains package.json.
2. Open Terminal > New Terminal.
3. Run: npm install
4. Run: npm run dev
5. Open the localhost URL printed in the terminal.

IMPORTANT
This is a frontend-only demonstration. Login accounts and student/faculty data are stored in the browser's localStorage. It is suitable for a frontend project demo, not production authentication. For production, connect a backend and secure password storage/role authorization.
